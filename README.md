# Project 3 — End-to-End Sales Analytics Capstone

## 📌 Project Overview

This project is an **end-to-end data analytics capstone** based on a retail sales dataset.

The project demonstrates the complete data analysis workflow:

* Data collection and loading
* Data cleaning
* Data preprocessing
* Exploratory Data Analysis (EDA)
* KPI analysis
* Data visualization
* Business insights
* Actionable recommendations
* Exporting analysis results

The analysis is performed using a reproducible **Jupyter Notebook** containing both Python code and Markdown explanations.

The main objectives of this project are:

## 📈 KPI Analysis

Key Performance Indicators are calculated to summarize business performance.

### KPIs

**Total Sales**

Measures the total revenue generated from all orders.

**Total Profit**

Measures the total profit generated by the business.

**Total Orders**

Counts the number of unique orders.

**Average Order Value**

Measures the average amount spent per order.

```text
Average Order Value =
Total Sales / Total Orders
```

**Profit Margin**

Measures profitability relative to sales.

```text
Profit Margin =
(Total Profit / Total Sales) × 100
```

These KPIs provide a quick overview of the overall health of the business.

## 🔍 Exploratory Data Analysis

The project investigates the following business questions:

### 1. Which product categories generate the most sales?

Sales are grouped by category to identify the strongest product segments.

### 2. Which products are the top performers?

The top 10 products are identified based on total sales.

### 3. Which regions perform best?

Sales, profit, and number of orders are compared across regions.

### 4. How do sales change over time?

Monthly sales are analyzed to identify growth patterns and seasonal trends.

### 5. Does higher sales always mean higher profit?

Sales and profit are compared to identify potentially low-profit or loss-making sales.

### 6. How does discounting affect profitability?

Discount levels are compared with profit to understand the effect of promotions.

## 💡 Actionable Insights

The analysis produces three main types of business recommendations.

### Insight 1 — Focus on High-Performing Categories

The category with the highest sales should receive additional attention through:

* Inventory planning
* Marketing
* Product availability
* Promotional campaigns

### Insight 2 — Improve Regional Performance

The strongest region can be used as a benchmark.

The company can investigate why that region performs well and apply successful strategies to weaker regions.

### Insight 3 — Optimize Discounts

Sales should not be evaluated using revenue alone.

High discounts can increase sales while reducing profit. Therefore, promotional campaigns should focus on products and customer segments where discounts produce profitable additional sales.
